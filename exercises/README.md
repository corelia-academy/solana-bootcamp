# Bài tập thực hành

Mỗi bài tập có một điểm bắt đầu và lời giải tham khảo. Hãy tự hoàn thành phần thực hành và chạy kiểm thử trước khi mở `solution`.

- [Rust Poll Counter](./rust-poll-counter/README.md) — luyện tập Rust qua một ứng dụng dòng lệnh nhỏ.
- [Privacy & ZK Lab](./privacy-zk-lab/README.md) — mô phỏng commitment, proof binding và nullifier.
- [Data Indexing Lab](./indexing-lab/README.md) — xử lý event và xây dựng trạng thái có thể truy vấn.
- [Forecasting App Lab](./forecasting-lab/README.md) — triển khai logic thị trường dự đoán giả lập.
- [Solana Security CTF](./security-ctf/README.md) — khai thác và nhận diện bốn lỗi bảo mật phổ biến.

Các project lớn hơn sử dụng bốn trạng thái `starter`, `checkpoint-1`, `checkpoint-2` và `final`; xem [danh sách project code-along](../projects/README.md).

Quay lại [chương trình học](../curriculum/README.md) hoặc [trang chính](../README.md).
