# Rust Poll Counter

Bài tập cuối Module 2, chưa sử dụng blockchain.

## Yêu cầu

- parse `yes`, `no`, `abstain` không phân biệt hoa thường;
- reject input khác bằng typed error;
- cập nhật ba counters bằng checked arithmetic;
- hiển thị tổng vote;
- không dùng `unwrap` cho input người dùng;
- toàn bộ unit tests pass.

## Chạy bài tập

```shell
cd exercise
cargo test
cargo run
```

Chỉ mở `solution` sau khi đã tự hoàn thành TODO và tests.
