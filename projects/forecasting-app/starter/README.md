# Forecasting App — Starter

Workspace compile được với state schema (Question, Player, Position), `CreateQuestion` và các lỗi đầu tiên. Học viên viết lần lượt `create_question`, `register_player`, `predict`, `resolve`, `claim` và tests.

> Điểm giả lập — không phải tiền thật.

## Mục tiêu state
Hiểu ba account và state machine `Open → Closed → Resolved` trước khi viết handler.
## Phần đã có
Workspace, state schema, PDA seeds của Question và test contract.
## Học viên cần làm
Làm theo [code-along](../../../curriculum/module-14-forecasting/code-along.md) từ bước 2c.
## Chạy và kiểm tra
`pnpm install && anchor keys sync && anchor build && anchor test`
