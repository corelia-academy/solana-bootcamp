# Forecasting App — Checkpoint 2

Đã có điểm giả lập, `predict` và `resolve` cùng 12 test (code-along bước 4). Tiếp theo: `claim` chống claim hai lần và leaderboard.

## Mục tiêu state
Resolve chỉ bởi authority, sau giờ đóng, đúng một lần.
## Phần đã có
Toàn bộ đường Open → Closed → Resolved và test lỗi tương ứng.
## Học viên cần làm
`claim`, công thức score và leaderboard.
## Chạy và kiểm tra
`pnpm install && anchor keys sync && anchor build && anchor test`

Bộ test chờ khoảng 20 giây để câu hỏi qua giờ đóng.
