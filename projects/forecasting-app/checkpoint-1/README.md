# Forecasting App — Checkpoint 1

Đã hoàn thành Question PDA và `create_question` cùng 3 test (code-along bước 2). Tiếp theo: sổ điểm giả lập, `predict` và các test lỗi.

## Mục tiêu state
Tạo câu hỏi có nội dung giới hạn, 2–4 lựa chọn và giờ đóng ở tương lai.
## Phần đã có
`create_question` và test giờ đóng / số lựa chọn.
## Học viên cần làm
Player PDA, Position PDA và `predict`.
## Chạy và kiểm tra
`pnpm install && anchor keys sync && anchor build && anchor test`
