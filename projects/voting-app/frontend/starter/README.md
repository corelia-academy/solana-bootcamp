# Starter — Voting Frontend

Public interface nằm ở `src/domain.ts`. Hoàn thiện client adapter và mở dần các acceptance tests; chưa cần styling hoặc Devnet ở bước này.

## Mục tiêu state
Giữ UI phụ thuộc typed client interface thay vì RPC trực tiếp.
## Phần đã có
Domain types, mock shell và acceptance tests.
## Học viên cần làm
Hoàn thiện load states và cluster-aware Explorer URL.
## Chạy và kiểm tra
`pnpm install && pnpm test && pnpm run build`
