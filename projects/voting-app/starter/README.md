# Voting App — Starter

Workspace compile được với state schemas và account constraints. Học viên hoàn thiện lần lượt `initialize_poll`, `add_candidate`, `vote` và tests.

## Mục tiêu state
Hiểu Poll/Candidate/VoteReceipt schema trước khi code handler.
## Phần đã có
Workspace, state schemas, PDA seeds và test contract.
## Học viên cần làm
Mở lần lượt initialize, candidate và vote flow.
## Chạy và kiểm tra
`pnpm install && anchor build && anchor test`
