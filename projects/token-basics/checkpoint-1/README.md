# Checkpoint 1 — Mint và ATA

Đã có amount helpers, tạo mint và hai ATA. Tiếp theo dùng `mintToChecked` và `transferChecked`, đúng mint, owner và decimals.

## Mục tiêu state
Tạo đúng mint và ATA theo owner.
## Phần đã có
Amount helpers, mint và hai ATA.
## Học viên cần làm
Mint và transfer bằng checked instructions.
## Chạy và kiểm tra
`pnpm install && pnpm run check && pnpm test`
