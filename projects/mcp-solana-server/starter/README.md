# Starter — MCP Solana Server

Giữ nguyên typed core interface; hoàn thiện validation, read tools rồi write policy. Acceptance tests đang skip có chủ ý.

## Phần đã có
Typed core interface và acceptance-test contract.
## Học viên cần làm
Hoàn thiện input validation và read tools.
## Chạy và kiểm tra
`pnpm install && pnpm run check && pnpm test`
