# Checkpoint 1 — Read tools

Balance/token holdings đã validate input, bound results và trả structured retryable RPC errors. Tiếp theo là write policy.

## Mục tiêu state
Đọc state qua injectable RPC với kết quả bounded.
## Phần đã có
Balance, holdings và structured retryable errors.
## Học viên cần làm
Thêm authenticated writes, allowlist, cap và simulation.
## Chạy và kiểm tra
`pnpm install && pnpm run check && pnpm test`
