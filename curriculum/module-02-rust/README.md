# Module 2: Rust Survival Kit

## Kết quả đầu ra

Đọc, viết, test và debug phần Rust cần thiết cho các Anchor program nhập môn.

## Bài học

Đọc [nội dung chi tiết từng lesson](./lessons.md).

1. Cargo projects, `Cargo.toml`, and modules
2. Variables, numeric types, booleans, and strings
3. Structs and `impl`
4. Enums and pattern matching
5. `Option`, `Result`, and error handling
6. Ownership and borrowing
7. Derive and attribute macros
8. Unit tests

## Bài tập

Xây Poll Counter chạy terminal, validate input `Yes/No/Abstain`, tính tổng kết quả, không panic vì input người dùng và có unit tests cho success/error.

Code exercise: [Rust Poll Counter](../../exercises/rust-poll-counter/README.md).

## Mental model

`struct` = data shape; `impl` = behavior; `enum` = allowed states; `Result<T,E>` = explicit outcome; macro = compile-time code helper.

## Điều kiện tiên quyết

Hoàn thành Module 1 và chạy được Rust/Cargo.
