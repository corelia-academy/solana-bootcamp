# Module 1: Orientation & Dev Environment

## Kết quả đầu ra

Học viên hiểu lộ trình bootcamp, giải thích được Anchor workspace và có toolchain local cùng Devnet wallet hoạt động.

## Bài học

Đọc [nội dung chi tiết từng lesson](./lessons.md).

1. Bootcamp map, scope, expectations, and what not to learn yet
2. macOS, Linux, and Windows WSL2 install paths
3. Anchor folder structure
4. Locked Rust, Solana CLI, Anchor, Node/package-manager versions
5. Common setup errors
6. Local wallet, Devnet faucet, and Explorer

## Cấu trúc bắt buộc

```text
my-project
├── Anchor.toml
├── programs/my_project/src/lib.rs
├── tests
├── app
├── target/idl
└── target/deploy
```

## Lab

Chạy `anchor init hello-solana`, `anchor build` và `anchor test` trong thư mục dùng thử. Hoàn thành [setup checklist](./setup-checklist.md).
