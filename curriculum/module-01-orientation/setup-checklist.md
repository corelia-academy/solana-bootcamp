# Module 1 setup checklist

- [ ] Supported macOS, Linux, or Windows WSL2 environment
- [ ] Rust, Cargo, Solana CLI, and Anchor match [course setup](../../docs/setup.md)
- [ ] Dedicated bootcamp wallet; no mainnet key reuse
- [ ] Devnet selected and wallet funded
- [ ] Explorer shows the correct Devnet address
- [ ] `anchor build` succeeds
- [ ] `anchor test` succeeds
- [ ] Learner can locate config, program, tests, IDL, and deploy artifact

Support requests include OS, command, complete error, tool versions, and attempted fixes.
