# Chương trình Module 0 + 18 module

Chương trình có tổng cộng 19 trang module: Module 0 để định hướng và học blockchain cơ bản; Module 1–18 để học, thực hành phát triển ứng dụng. Giữ nguyên số Module 1–18.

Mỗi module có trang riêng, mục tiêu đầu ra, lesson sequence, nội dung chi tiết và bài thực hành.

[Truy cập khóa học trên Corelia Academy](https://corelia.academy/learn/courses/solana-bootcamp) để học theo từng lesson cùng nội dung bổ trợ; dùng các trang trong repo để đọc docs và thực hành code tương ứng.

Xem [bản đồ phụ thuộc](../docs/module-dependencies.md) để biết prerequisite và sản phẩm được tái sử dụng giữa các module.
