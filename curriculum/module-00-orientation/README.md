# Module 0: Bootcamp Orientation

## Kết quả đầu ra

Học viên hiểu mục tiêu khóa học, chọn được hướng học dự kiến, tự đánh giá prerequisite và tìm đúng tài liệu/code trong GitHub repo. Học viên biết cách theo dõi video khi docs được cập nhật và hiểu vì sao cần dùng bộ phiên bản của khóa học.

## Điều kiện tiên quyết

Không có module tiên quyết. Khóa học dành cho người có kiến thức lập trình cơ bản; lesson 0.3 giúp xác định phần cần bổ sung trước khi thực hành.

## Truy cập khóa học

Học tại [Solana Bootcamp trên Corelia Academy](https://corelia.academy/learn/courses/solana-bootcamp) để theo dõi từng lesson cùng các nội dung bổ trợ. Kết hợp bài giảng video với docs, code và bài thực hành trong GitHub repo.

## Bài học

Đọc [nội dung chi tiết từng lesson](./lessons.md).

1. Welcome to the Solana Bootcamp
2. Your Learning Roadmap
3. Prerequisites & Readiness Check
4. How to Use the GitHub Repository
5. Video, Documentation & Tool Versions

## Thực hành

Ghi lại mục tiêu học, chọn một hướng capstone dự kiến và tìm tài liệu setup, troubleshooting cùng code thực hành của một module. Hoàn thành [readiness checklist](./readiness-checklist.md).

Module này chưa yêu cầu cài toolchain, tạo wallet hoặc viết Anchor code. Các thao tác đó bắt đầu ở Module 1.

## Điều kiện hoàn thành

- Xác định được mục tiêu và hướng học dự kiến.
- Biết phần kiến thức đầu vào cần bổ sung, nếu có.
- Tìm được tài liệu và phân biệt starter, checkpoint, final.
- Giải thích được quy tắc ưu tiên docs và sử dụng phiên bản công cụ.
- Hoàn thành readiness checklist và biết bước tiếp theo ở Module 1.
