# Module 0 readiness checklist

Checklist này xác nhận bạn hiểu cách học, kiến thức blockchain cơ bản và đã dùng thử Phantom/Explorer. Không yêu cầu terminal, toolchain hoặc Anchor.

- [ ] Ghi lại mục tiêu học và một sản phẩm/capstone dự kiến.
- [ ] Phân biệt core track, nhánh tự chọn và AI/Agent track.
- [ ] Tìm được prerequisite trên bản đồ phụ thuộc.
- [ ] Tự đánh giá 4 kỹ năng: đọc code cơ bản (biến, hàm, điều kiện, vòng lặp), terminal (`pwd`, `ls`, `cd`), Git (clone, diff, commit) và đọc lỗi; ghi phần cần ôn trước Module 1.
- [ ] Có laptop macOS, Linux hoặc Windows qua WSL2 và editor như VS Code; chưa cần cài công cụ.
- [ ] Tìm được README và lessons của Module 1.
- [ ] Tìm được [setup guide](../../docs/setup.md) và bảng phiên bản công cụ.
- [ ] Tìm được [troubleshooting](../../docs/troubleshooting.md).
- [ ] Tìm được code thực hành và phân biệt starter, checkpoint, final.
- [ ] Giải thích được nhịp học “Xem → Dừng video → Code → Test → Đối chiếu”.
- [ ] Biết ưu tiên GitHub docs của lesson/setup khi cách thao tác khác video.
- [ ] Biết phiên bản mới hơn có thể gây lỗi tương thích và chỉ cập nhật khi docs hướng dẫn.
- [ ] Biết thông tin cần ghi lại khi gặp lỗi và những secret không được chia sẻ.
- [ ] So sánh được Web1, Web2 và Web3: dữ liệu nằm ở đâu, ai đặt quy tắc, đăng nhập thế nào.
- [ ] Giải thích được ledger, state, block, hash và vai trò của đồng thuận bằng ví dụ đơn giản.
- [ ] Phân biệt public address, private key, seed phrase, keypair và signature.
- [ ] Phân biệt transaction, instruction, program và data account qua ví dụ bình chọn.
- [ ] Hiểu transaction thực thi lỗi có thể vẫn mất phí dù thay đổi ứng dụng được hoàn tác.
- [ ] Phân biệt localnet, Devnet và mainnet; hiểu đổi mạng không chuyển tài sản sang mạng khác.
- [ ] Phân biệt đọc dữ liệu qua RPC với gửi transaction có chữ ký và phí.
- [ ] Vẽ được luồng từ giao diện qua ví/RPC đến program và account; chỉ ra phần onchain/offchain.
- [ ] Biết signature chưa chứng minh transaction đã thành công; cần kiểm tra xác nhận, lỗi và đúng cluster.
- [ ] Giải thích được vì sao Solana chạy song song được.
- [ ] Vẽ được kiến trúc một ứng dụng Web2 và một ứng dụng Web3 trên Solana; chỉ ra lớp nào khác nhau.
- [ ] Ghi lại phần onchain/offchain cho một ứng dụng Web2 quen thuộc.
- [ ] Tự trả lời được tám câu hỏi cuối [nội dung lesson](./lessons.md#tự-kiểm-tra-trước-module-1).
- [ ] Cài Phantom, tạo ví học tập và chọn Solana Devnet.
- [ ] Nhận SOL thử từ faucet và kiểm tra số dư trong Phantom.
- [ ] Mở được ví và giao dịch nhận SOL trên Explorer Devnet; phân biệt địa chỉ ví với signature.
- [ ] Gửi 0.01 SOL Devnet tới bạn học hoặc account thứ hai, kiểm tra mạng, người nhận, số lượng và phí trước khi xác nhận.
- [ ] Chỉ ra được số dư, trạng thái, người gửi/nhận và ai trả phí; lưu ba link Explorer công khai (ví, giao dịch nhận, giao dịch gửi).
- [ ] Biết bước tiếp theo là đọc Module 1 và thực hiện setup theo docs hiện hành.

## Minh chứng hoàn thành

Lưu một ghi chú ngắn gồm mục tiêu học, hướng dự kiến, prerequisite cần ôn và đường dẫn setup/troubleshooting/code đã tìm. Thêm vài câu mô tả cách xử lý sai khác giữa video và docs, sơ đồ luồng bình chọn, câu trả lời bài tự kiểm tra và ba link Explorer của bài Phantom (ví, giao dịch nhận, giao dịch gửi). Không cần nộp version output hoặc test output ở Module 0.
