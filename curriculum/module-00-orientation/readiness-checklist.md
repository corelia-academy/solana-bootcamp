# Module 0 readiness checklist

Checklist này xác nhận bạn hiểu cách bắt đầu khóa học. Không yêu cầu cài toolchain, tạo wallet hay chạy Anchor.

- [ ] Ghi lại mục tiêu học và một sản phẩm/capstone dự kiến.
- [ ] Phân biệt core track, nhánh tự chọn và AI/Agent track.
- [ ] Tìm được prerequisite trên bản đồ phụ thuộc.
- [ ] Tự đánh giá lập trình cơ bản, terminal và Git; ghi phần cần ôn, nếu có.
- [ ] Tìm được README và lessons của Module 1.
- [ ] Tìm được [setup guide](../../docs/setup.md) và bảng phiên bản công cụ.
- [ ] Tìm được [troubleshooting](../../docs/troubleshooting.md).
- [ ] Tìm được code thực hành và phân biệt starter, checkpoint, final.
- [ ] Giải thích được nhịp học “Xem → Dừng video → Code → Test → Đối chiếu”.
- [ ] Biết ưu tiên GitHub docs của lesson/setup khi cách thao tác khác video.
- [ ] Biết phiên bản mới hơn có thể gây lỗi tương thích và chỉ cập nhật khi docs hướng dẫn.
- [ ] Biết thông tin cần ghi lại khi gặp lỗi và những secret không được chia sẻ.
- [ ] Biết bước tiếp theo là đọc Module 1 và thực hiện setup theo docs hiện hành.

## Minh chứng hoàn thành

Lưu một ghi chú ngắn gồm mục tiêu học, hướng dự kiến, prerequisite cần ôn và đường dẫn setup/troubleshooting/code đã tìm. Thêm vài câu mô tả cách xử lý sai khác giữa video và docs. Không cần nộp version output hoặc test output ở Module 0.
