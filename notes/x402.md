# x402 payment flow

[Mermaid source](./images/x402-flow.mmd)

![Luồng thanh toán x402](./images/x402-flow.png)

```mermaid
sequenceDiagram
    participant C as Client
    participant S as Paywall server
    participant L as Solana
    C->>S: GET /resource
    S-->>C: 402 payment requirements
    C->>L: sign/send exact payment
    C->>S: retry with payment proof
    S->>L: verify recipient, asset, amount, nonce
    S-->>C: 200 gated content
```

Production concerns include replay prevention, expiry, exact asset/recipient validation, confirmation level, concurrent requests, idempotency, refunds, and rate limits.
